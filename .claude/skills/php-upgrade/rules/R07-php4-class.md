## 何が起きるか
- **クラス名と同名のメソッド**は PHP 8.0 でコンストラクタとして扱われなくなった。`new C($row)` が**エラーにならずに**初期化されないオブジェクトを返す。
- **非 static メソッドを `C::m()` で呼ぶ**と PHP 8.0 で Error（Fatal）。
- `var $x;` は今も有効（public と同じ）。変更不要。
- 宣言のないプロパティへの代入（動的プロパティ）は PHP 8.2 で Deprecated。

## 直し方
- 同名メソッド → `__construct`。親クラスのコンストラクタを `parent::ClassName()` で呼んでいる箇所は `parent::__construct()` に。
- `C::m()` で呼ばれているメソッドで、本体が `$this` を使わないものに `static` を付ける（5.0 でも有効）。`$this` を使っているなら呼び出し側をインスタンス経由にする。
- 動的プロパティはクラスに宣言を足す（振る舞いは変わらない）。

## 落とし穴
- 同じクラスに `__construct` と同名メソッドの両方がある場合は、旧環境でも `__construct` が優先されていた。
- 同名メソッドを「普通のメソッドとして」別の場所から呼んでいる場合（`$obj->Product($row)`）は、名前を残したラッパーが要る。
- `detect` の `C::m(` は `parent::` `self::` も拾う。静的呼び出しの候補を目で確認する。
