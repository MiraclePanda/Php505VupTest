# 移行ルールカタログ

PHP 5.0.x → 8.5 の移行で適用するルールの一覧。1 ファイル 1 ルール。
`scripts/upgrade/scan.py` は各ファイル先頭の `detect` を読んで機械的に候補を洗い出す。

## 書式

```
---
id: R01                      # 一意な ID。コミットメッセージにも入れる
title: 短縮オープンタグ
phase: 3A                    # docs/upgrade-process.md のフェーズ
category: 実行設定依存
order: 10                    # 適用順（小さい順）。依存関係があるルールはここで順序を決める
detect:                      # Python の正規表現。1 行 1 パターン。シングルクォートで囲む
  - '<\?(?![pP][hH][pP]|=|xml)'
---
本文: 何が起きるか / 直し方 / 落とし穴 / 確認方法 / 学び（過去の実施で分かったこと）
```

## 運用

- 実施中に新しい落とし穴を見つけたら、該当ルールの「学び」に追記する（日付と実施 ID を付ける）。
- どのルールにも当てはまらない課題は、新しいルールファイルを作る。
- `detect` で拾えなかった課題（見逃し）は、パターンを足すか、拾えない理由を「学び」に書く。
